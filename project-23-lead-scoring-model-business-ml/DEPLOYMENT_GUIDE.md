# LeadForge AI - Production Deployment Guide

## 🚀 Deployment Options

### Option 1: Railway.app (Recommended - 5 minutes)

**Why Railway?**
- ✅ Automatic Docker deployment
- ✅ PostgreSQL + Redis included
- ✅ One-click deploy
- ✅ Free tier available
- ✅ Environment management

#### Step-by-Step:

1. **Create Railway Account**
   ```bash
   # Visit https://railway.app
   # Sign up with GitHub/email
   ```

2. **Install Railway CLI**
   ```bash
   npm i -g @railway/cli
   railway login
   ```

3. **Initialize Project**
   ```bash
   cd LeadForge-AI-Complete
   railway init
   # Select "Deploy from GitHub" or "Docker"
   ```

4. **Add Services**
   ```bash
   # Create PostgreSQL
   railway add postgresql
   
   # Create Redis
   railway add redis
   
   # Deploy backend
   railway deploy
   ```

5. **Set Environment Variables**
   ```bash
   railway variables set DATABASE_URL=<auto-generated>
   railway variables set REDIS_URL=<auto-generated>
   railway variables set API_SECRET_KEY=<generate-strong-key>
   railway variables set ENVIRONMENT=production
   ```

6. **Get API URL**
   ```bash
   railway logs
   # API will be at: https://<your-project>.up.railway.app
   ```

### Option 2: Docker on EC2/VPS

**Prerequisites:**
- AWS EC2 instance (t3.medium minimum)
- Ubuntu 22.04 LTS
- SSH access

#### Setup:

```bash
# 1. Connect to EC2
ssh -i your-key.pem ec2-user@your-instance-ip

# 2. Update system
sudo apt update && sudo apt upgrade -y

# 3. Install Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 4. Install Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.23.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 5. Clone repository
git clone <your-repo-url> leadforge
cd leadforge

# 6. Create .env
cp .env.example .env
# Edit .env with production settings

# 7. Start services
docker-compose -f docker-compose.yml up -d

# 8. Verify
curl http://localhost:8000/api/v1/health
```

### Option 3: Kubernetes on GKE

**For enterprise deployments**

```bash
# 1. Create GKE cluster
gcloud container clusters create leadforge \
  --region us-central1 \
  --num-nodes 3

# 2. Install kubectl
gcloud components install kubectl

# 3. Create namespace
kubectl create namespace leadforge

# 4. Deploy with Helm (recommended)
helm repo add leadforge https://charts.leadforge.ai
helm install leadforge leadforge/leadforge -n leadforge -f values.yaml

# 5. Verify deployment
kubectl get pods -n leadforge
kubectl port-forward svc/leadforge-api 8000:8000 -n leadforge
```

## 🔄 CI/CD Pipeline

### GitHub Actions Example

```yaml
# .github/workflows/deploy.yml
name: Deploy to Railway

on:
  push:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      
      - name: Install dependencies
        run: pip install -r backend/requirements.txt
      
      - name: Run tests
        run: pytest tests/ --cov=backend
      
      - name: Check code quality
        run: |
          black --check backend/
          flake8 backend/
          mypy backend/

  deploy:
    needs: test
    runs-on: ubuntu-latest
    if: success()
    steps:
      - uses: actions/checkout@v3
      - name: Deploy to Railway
        run: |
          npm i -g @railway/cli
          railway login --token ${{ secrets.RAILWAY_TOKEN }}
          railway up
```

## 🆘 Troubleshooting Production Issues

### API Down

```bash
# Check service status
docker-compose ps

# Check logs
docker-compose logs backend

# Restart service
docker-compose restart backend

# Check health endpoint
curl http://localhost:8000/api/v1/health
```

### Database Connection Issues

```bash
# Check connection
psql $DATABASE_URL

# Check connection pool
SELECT datname, usename, application_name, state FROM pg_stat_activity;

# Kill idle connections if needed
SELECT pg_terminate_backend(pid) FROM pg_stat_activity 
WHERE state = 'idle' AND query_start < now() - interval '30 minutes';
```

### Model Inference Slow

```bash
# Check model loading
python3 -c "from backend.services.ml_service import MLService; m = MLService(...); print(m.is_loaded)"

# Check if GPU available
nvidia-smi

# Profile inference
python3 -m cProfile -s cumtime backend/app.py
```

### Memory Leaks

```bash
# Monitor memory usage
docker stats leadforge-backend

# Enable memory profiling
pip install memory-profiler
python3 -m memory_profiler backend/app.py
```
